# 唇釉瓶可支持图库分类参考

> 目标：约100张可被AiCad系统建模的唇釉瓶参考图片，按瓶型分门别类
>
> **已完成：114张图片下载到 14 个分类目录中**
>
> 系统支持能力：圆形/方形截面 × 直筒/锥度/曲线轮廓 × flat/dome/pointed 盖顶 × 5种防滑纹

---

## 分类总览

| 大类 | 子类 | 数量目标 | 系统匹配度 |
|------|------|---------|-----------|
| A. 圆形直筒 | A1 平顶盖 / A2 圆顶盖 / A3 尖顶盖 | 30 | 85-95% |
| B. 圆形曲线 | B1 锥形 / B2 收腰 / B3 水滴 / B4 S形 | 25 | 75-90% |
| C. 方形截面 | C1 方直筒 / C2 方锥度 / C3 大圆角 | 25 | 75-85% |
| D. 特殊盖型 | D1 纹理盖 / D2 蘑菇盖 / D3 锥度盖 / D4 光面盖 | 20 | 70-85% |
| **合计** | | **~100** | |

### 采集标准

每张图片需满足：
1. **单瓶清晰** — 白底/纯色背景最佳，能看清瓶型轮廓
2. **截面可判断** — 能分辨圆形还是方形
3. **盖型可识别** — 能看到盖顶形态（平/圆/尖）
4. **无超复杂特征** — 排除钻石切面、竹纹、开窗等
