# AiCad Report Index

This directory is split by product generation:

- `V2/` - reports and release notes for the current AiCad V2 branch: parametric cosmetic packaging CAD, VLM-assisted image-to-parameter pipeline, gallery/showroom preview, STEP/STL/SVG outputs, and assembly/QC workflows.
- `V3/` - research and implementation plans for the next major line: creative image generation, AIGC 3D exterior shell generation, and AiCad reconstruction into production CAD.
- Root-level reports are historical V2 research drafts kept in place for traceability. New reports should be placed in a versioned subdirectory.

Version rule:

- V2 reports describe what exists or was prototyped in the current branch.
- V3 reports describe the target workflow and new architecture. They must not be mixed into V2 release notes unless a feature has actually shipped.
