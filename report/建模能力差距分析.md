# 建模器缺陷分析报告

## 测试背景

基于 14 分类 / 19 张抽检图片的 VLM 管线端到端测试，以及对 `src/core/modeler.py` 的逐行审查。

|---|------|--------|------|---------|

## 新增建模路径覆盖

测试管线现在在 skip-vlm 模式下覆盖以下新路径：

| 分类 | 覆盖特征 |
|------|---------|
| A2_round_dome | dome 真球冠 |
| A3_round_pointed | pointed 锥顶 |
| B1_tapered | taper 瓶身 + angular 肩部 + fillet |
| B2_barrel | bottle spline + cap spline + sloped 肩部 |
| B3_teardrop | bottle spline + convex 底部 |
| B4_scurve | bottle spline + cap spline |
| C2_square_taper | 方形锥度 + sloped 肩部 |
| D1_textured_cap | ribs 防滑纹 |
| D2_mushroom_cap | 蘑菇盖比例 1.15 |
| D3_taper_cap | 盖锥度 4° |

## OCCT 已知结构性弱点（无法根治，需降级兜底）

| 弱点 | 触发条件 | 失败率 | 应对 |
|------|---------|--------|------|
| Fillet 在 B-spline 面上失败 | spline 模式 + 较大 fillet | 10-15% | try_feature 降级 |
| 布尔运算 coplanar 面 | union/cut 两体共面 | ~5% | 面偏移 eps |
| thin-wall 布尔切割 | 壁厚 <0.5mm | ~5% | 壁厚下限保护 |

## CadQuery 能力结论

CadQuery (OCCT) 可支持所有唇釉瓶类型，没有理论死角。所有缺陷均为代码实现问题，不是引擎能力限制。现已全部修复。
