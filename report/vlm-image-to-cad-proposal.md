# VLM 图片驱动 CAD 生成 - 技术方案报告

> 日期：2026-03-02
> 项目：AiCad 唇釉瓶参数化 CAD 系统
> 范围：从灵感图片自动生成 STEP 工程模型的可行性分析与实施路线

---

## 1. 背景与动机

### 1.1 当前系统的局限

AiCad 目前采用纯参数化输入模式：用户需手动指定 20+ 个精确参数（外径、总高、锥度角、螺纹规格等），系统通过 CadQuery 生成 STEP + STL + 工程图。

**问题：** 如果工程师有精力微调这么多参数，他们也能直接在 SolidWorks/Fusion360 里建模。系统的真正价值应该是**降低输入门槛**。

### 1.2 理想的工作流

```
工程师的灵感（一张图片/一段描述）
        ↓
   AI 理解 → 提取参数
        ↓
   现有生成器 → STEP + 工程图
        ↓
   工程师微调 2-3 个关键参数 → 最终成品
```

### 1.3 核心问题

| 问题 | 描述 | 难度 |
|------|------|------|
| **A. 图片 → 参数** | 从灵感图提取足够生成模型的参数 | 中等 |
| **B. 不规则外观生成** | 系统能否生成小兔子造型等异形瓶盖 | 极高 |

## 2. 技术调研结论

### 2.1 Image-to-3D 模型现状（2025-2026）

| 模型 | 参数量 | 输出格式 | 质量 | 速度 (H100) | 能输出 STEP？ |
|------|--------|---------|------|-------------|--------------|
| **TRELLIS.2** (微软) | 4B | OBJ/GLB 三角网格 | 极高 | ~3s (512^3) | 否 |
| **Hunyuan3D 2.5** (腾讯) | 10B | OBJ/GLB | 高 | ~10s | 否 |
| **Rodin Gen-2** (Deemos) | 10B | 四边面网格 | 高 | ~15s | 否 |
| **TripoSR** (Stability AI) | - | OBJ | 中 | ~0.5s | 否 |
| **BrepGen** (Autodesk Research) | - | B-Rep | 研究阶段 | - | 是，但不接受图片输入 |

**结论：所有可用的 AI 3D 生成模型只输出三角网格，不输出 B-Rep/STEP。**

### 2.2 Mesh → B-Rep/STEP 转换

| 形状类型 | 转换可靠性 | 最佳工具 |
|---------|-----------|---------|
| 规则几何体（圆柱、锥面） | >90% | Geomagic Design X（商业，~10万/年）|
| 旋转对称体（瓶身、瓶盖） | 高 | Geomagic |
| 有机自由曲面 | ~60-70% | 仅 Geomagic |
| AI 生成的 mesh（有噪声） | ~30-50% | 需大量手动修复 |

**结论：mesh → STEP 对不规则形状不可靠，是整个行业的技术瓶颈。**

### 2.3 VLM 几何参数提取能力

基于 MeasureBench (2025) 等基准测试：

| VLM 能力 | 可靠性 | 说明 |
|---------|--------|------|
| 分类形状（圆柱/锥形/圆顶/扁平） | **高** | VLM 强项 |
| 提取比例（高宽比、盖/身比） | **中高** (±5-10%) | 需 1 个锚定尺寸 |
| 识别特征（螺纹、防滑纹、凸环） | **高** | VLM 强项 |
| 读取工程图上的标注尺寸 | **高** | VLM 强项 |
| 提取绝对 mm 尺寸 | **不可能** | 照片无尺度信息 |
| 精确角度/曲率 | **低** | 单张照片有深度模糊 |

**结论：VLM 不能从照片直接读出毫米数，但能可靠地提取比例和特征分类。配合用户提供的 1 个锚定尺寸，即可映射出完整参数集。**

### 2.4 CadQuery 自由曲面能力

CadQuery 2.6.1（项目当前版本）支持但项目未使用的高级功能：

| 功能 | API | 适用场景 |
|------|-----|---------|
| B 样条曲线 | `spline()` | 自由轮廓曲线 |
| 路径扫掠 | `sweep()` | 沿曲线路径生成实体 |
| 多截面放样 | `loft()` (multisection) | 不同截面间光滑过渡 |
| 旋转体 | `.revolve()` | 轮廓曲线绕轴旋转 |
| NURBS 曲面 | OCP `Geom_BSplineSurface` | 复杂自由曲面（需底层 API）|

**结论：CadQuery 完全具备生成曲线瓶身、弧面肩部等有机形态的能力，只是当前代码未使用。**

## 3. 当前系统的结构性优势

代码分析发现 `modeler.py` 天然地将**外观层**与**内部结构层**分离：

```
┌──────────────────────────────────┐
│         外观层 (可替换)            │  _loft_frustum() 锥面、dome 顶面、grip 纹理
│   纯视觉，不影响装配              │  → 可用 spline/revolve/loft 替代
├──────────────────────────────────┤
│        内部结构层 (不可动)          │  螺纹(twistExtrude)、内腔(extrude)、密封环
│   精确尺寸，决定装配配合           │  壁厚、间隙常量、公差
└──────────────────────────────────┘
```

各组件外观 vs 内部操作统计：

| 组件 | 外观操作 | 内部结构操作 | 可替换度 |
|------|---------|-------------|---------|
| Cap | 1 loft + dome fillet + grip | 1 cavity extrude + threads | 外壳可替换 |
| Bottle | 3 loft (body/shoulder/neck) | 2 cavity extrude + threads | 外壳可替换 |
| Wiper | 1 loft + diaphragm | 1 cavity + orifice + flange | 外壳可替换 |
| Wand | 2 loft (cap/stem) + brush | 1 cavity + seal ring + threads | 外壳可替换 |

## 4. 三阶段实施路线

### Phase 1：VLM 图片 → 参数提取（推荐优先）

**目标：** 用户上传灵感图 + 1 个已知尺寸 → 自动填充所有参数 → 现有生成器出图

**数据流：**

```
用户输入                          系统处理
┌──────────────┐              ┌───────────────────┐
│  灵感图片     │ ──────────→ │  VLM (Claude API)  │
│  + "总高95mm" │              │  Structured Output │
└──────────────┘              └─────────┬─────────┘
                                        │
                   JSON:                ↓
                   {
                     cap_height_ratio: 0.28,    // 盖高 ≈ 28% 总高
                     body_od_ratio: 0.22,       // 瓶身OD ≈ 22% 总高
                     taper_deg: ~3,             // 微锥度
                     top_shape: "dome",         // 圆顶
                     shoulder_style: "round",   // 圆肩
                     grip_style: "ribs",        // 竖筋
                   }
                                        │
                                        ↓
                             ┌───────────────────┐
                             │ 比例 × 95mm        │
                             │ → 绝对参数          │
                             │ → 现有 CadQuery    │
                             │ → STEP + 工程图     │
                             └───────────────────┘
```

**技术实现要点：**
- 前端：新增「上传灵感图」入口，支持拖拽/粘贴图片
- 后端：调用 Claude Vision API，使用结构化 Prompt 提取比例和特征
- Prompt 模板：包含所有可能的参数键、取值范围、枚举选项
- 用户确认：VLM 输出参数后填入表单，用户可微调后再生成

**预期效果：** 工程师从调 20+ 参数 → 只需确认/微调 2-3 个关键值

**工作量：** 2-3 周 | **可行性：** 高 | **价值：** 极高

---

### Phase 2：Spline 轮廓驱动（有机但轴对称形状）

**目标：** 支持曲线瓶身、弧面肩部等非直线轮廓的造型

**当前限制：**
```python
# modeler.py 当前方式：只能直线锥面
_loft_frustum(r_bottom=10, r_top=8, h=25)
```

**升级方案：**
```python
# 新方式：spline 轮廓控制点 + revolve
profile_points = [(10, 0), (11, 8), (9.5, 16), (8, 25)]
body = cq.Workplane("XZ").spline(profile_points).close().revolve(360)
```

**轮廓提取方式：**
1. CV：边缘检测 → 轮廓提取 → 拟合 5-8 个 spline 控制点
2. VLM：描述轮廓特征 → 映射为预定义控制点模板
3. 用户手动：前端提供可视化控制点编辑器

**覆盖范围：** 90%+ 真实化妆品包装设计（大多数瓶身为旋转对称体）

**工作量：** 3-4 周 | **可行性：** 高 | **价值：** 高

---

### Phase 3：AI 3D + 混合建模（不规则造型，长期探索）

**目标：** 支持小兔子、花朵等非对称异形造型

**技术路线：**

```
灵感图 → TRELLIS.2 → 三角网格 (外观 mesh)
                          ↓
                     网格简化 + 清理
                          ↓
               ┌──────────┴──────────┐
               │   外壳 (mesh)        │  ← AI 生成的自由曲面
               │   + Boolean Cut      │
               │   内部结构 (B-Rep)    │  ← 现有参数系统生成的腔体/螺纹
               └─────────────────────┘
                          ↓
                     输出 STL (非 STEP)
```

**明确限制：**
- 只能出 STL，不能出可编辑的 STEP（mesh → B-Rep 不可靠）
- 需要 GPU 服务器运行 TRELLIS.2（H100 推荐）
- mesh + B-Rep 混合 Boolean 操作稳定性待验证
- 适合概念验证 / 3D 打印原型，不适合直接开模生产

**工作量：** 探索性 | **可行性：** 中低 | **价值：** 中

## 6. Phase 1 详细设计

### 6.1 前端交互流程

```
┌─────────────────────────────────────────┐
│  [选择产品] [选择组件] [风格预设]         │
│                                         │
│  ┌─────────────────────────────────┐    │
│  │  📷 上传灵感图 (拖拽/粘贴/选择)  │    │
│  │  ┌─────────┐                    │    │
│  │  │  图片    │  已知尺寸: [95] mm │    │
│  │  │  预览    │  尺寸类型: [总高▼]  │    │
│  │  └─────────┘                    │    │
│  │  [🔍 AI 分析提取参数]            │    │
│  └─────────────────────────────────┘    │
│                                         │
│  参数面板（AI 自动填充，用户可微调）      │
│  外径: [19.04] mm  ← AI推荐              │
│  总高: [50.00] mm  ← 用户锚定             │
│  锥度角: [3.0] °   ← AI推荐              │
│  ...                                     │
│                                         │
│  [生成 STEP + 3D预览 + 工程图]           │
└─────────────────────────────────────────┘
```

### 6.2 VLM Prompt 设计要点

```
你是一个化妆品包装工程专家。请分析这张唇釉瓶 {component} 的图片，
提取以下参数的比例或分类值。

用户提供的锚定尺寸：{anchor_param} = {anchor_value} mm

请输出 JSON，包含：
- 所有可推断的参数比例（相对于锚定尺寸）
- 特征分类（top_shape, shoulder_style, grip_style 等）
- 置信度评分（0-1）
- 无法判断的参数标注为 null
```

### 6.3 后端 API 设计

```
POST /api/vision/extract
Body: { image: base64, component: "cap", anchor_param: "height_mm", anchor_value: 50 }
Response: {
  params: { outer_od_mm: 19.0, height_mm: 50.0, taper_deg: 3.0, ... },
  confidence: { outer_od_mm: 0.75, taper_deg: 0.6, ... },
  description: "圆顶瓶盖，微锥度，竖筋防滑纹，约3:1高宽比"
}
```

### 6.4 依赖

- Claude API (claude-sonnet-4-6 with vision)，约 $0.01-0.03/次调用
- 前端：图片上传组件 + 置信度指示器
- 后端：新增 `/api/vision/extract` 端点

## 7. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| VLM 比例估计偏差 >15% | 中 | 参数不合理 | 加入参数校验规则，超范围提示用户 |
| 用户不提供锚定尺寸 | 高 | 无法算绝对值 | 使用行业标准默认尺寸 + 提示 |
| 非标准造型无法分类 | 低 | 特征选错 | 回退到最近预设 + 用户确认 |
| API 调用延迟 >5s | 低 | 用户体验差 | loading 动画 + 缓存相似查询 |

---

## 8. 结论

1. **Phase 1（VLM 图片→参数）是最高 ROI 的投入**，不需要修改 CadQuery 生成器，2-3 周可落地
2. **Phase 2（Spline 轮廓）是自然延伸**，CadQuery 2.6.1 已具备能力，项目架构（外观/内部分离）天然支持
3. **Phase 3（AI 3D 异形）目前不建议投入**，mesh→STEP 是行业级瓶颈，等技术成熟后再考虑
4. 当前系统的参数化内部结构（螺纹、内腔、密封、公差）是核心竞争力，任何扩展都应保留这一层不变
