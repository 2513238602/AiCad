# VLM + CV 各擅所长方案

## 现状问题

A3 自动管线失败的核心原因：**CV 的盖/身分界检测（颜色法）对透明瓶身+有色盖的产品严重失准**。
颜色法找"HSV 梯度最大跳变点"，但透明六边形瓶身内部折射/背景变化产生了假跳变，
导致分界线偏低（60.9% 判给了盖，实际只有约 15%）。

而 VLM（即使开了思考模式）在定量比例上也不准（盖高比例识别为 50%，实际约 15%）。

## 各自擅长的能力

| 能力 | VLM | CV |
|------|-----|-----|
| 截面形状（六边形/圆形/方形） | 准确 | 无法判断 |
| 顶部形状（尖顶/圆顶/平顶） | 准确 | 无法判断 |
| 肩部风格（圆滑/锐角/斜面） | 准确 | 无法判断 |
| 装饰风格（竖纹/光面/滚花） | 准确 | 无法判断 |
| 多轮廓分类（装配体/单独瓶/盖） | 无法做 | 准确 |
| 瓶身宽度轮廓（颈径/肩高/体径） | 不准 | 准确（独立瓶身轮廓） |
| 锥度角 | 不准 | 准确（整件轮廓拟合） |
| 盖/身高度比例 | 不准 | 问题所在（颜色法失准） |
| 装饰带尺寸（collar/底座台阶） | 粗估 | 准确（边缘密度法） |

## 核心思路

**盖/身分界不再依赖颜色法，改用"独立瓶身轮廓"反推。**

图中有 3 类轮廓（已准确分类）：
- 装配体（#0 绿色）：盖+瓶合体，测总高、锥度、宽度
- 独立瓶身（#1 红色）：纯瓶身，测瓶身高度、颈径、肩高、体径
- 打开的盖（#2 蓝色）：盖+刷杆，测盖高度

新策略：
1. 装配体轮廓 → 测总高像素、整件锥度、底部宽度
2. 独立瓶身轮廓 → 测瓶身高度像素、颈径、肩高、体径
3. **盖高 = 总高 - 瓶身高度**（用独立轮廓的瓶身高度反推，不再用颜色边界）
4. 如果有打开的盖轮廓 → 直接测盖高度，与反推值交叉验证
5. 如果只有装配体（无独立轮廓） → 保留现有颜色法+几何法作为回退

## 具体改动

### 只改 `cv_measure()` 函数（auto_pipeline.py）

在现有"独立 bottle 交叉校验"逻辑之后，增加一个步骤：

**如果有独立瓶身轮廓 → 用它的高度反推盖高**

```
独立瓶身高度（像素）/ 装配体总高度（像素）= 瓶身占比
盖高 = 总高mm × (1 - 瓶身占比)
```

这比颜色法可靠得多，因为独立瓶身轮廓的上下边界就是实际瓶身的上下边界，不受颜色干扰。

### 不改动的部分

- VLM 提取逻辑（vlm_extract.py）不动
- 颜色法/几何法代码保留作为回退（无独立轮廓时仍需要）
- 多轮廓分类逻辑不动
- 独立瓶身颈部测量不动
- merge_cv_vlm 合并策略不动
- 其他产品的 VLM 缓存不动

### 回退机制

- 部分参考图可能没有独立瓶身轮廓（只有装配体）→ 回退到现有颜色法
